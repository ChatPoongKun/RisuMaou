alpha v_0.1 (26.01.15)

리수마왕이 렐름에 최초공개된 버전입니다.

현재 고유 캐릭터인 갈피빈유 마오에 대한 조교를 체험해볼 수 있도록 구현되어 있습니다.

큼직한 컨텐츠만 따져도 임신시스템, 요의 시스템, 신규 캐릭터 생성, 함정 및 몬스터관리, 용사의 침입과 격퇴, 마을 침공, 광왕과의 상호작용 등 구현해 나가야 할 것이 산더미 처럼 많습니다.

LLM을 활용한 진짜 텍스트 게임을 만들고자 열심히 개발했지만 어디서 어떤 버그가 터질지도 모릅니다.

버그 제보나 개발 아이디어를 주고자 하는 분은 아카라이브 챗챈에서 리수마왕을 키워드로 글을 작성해주시거나

깃헙 의 데브브런치에 지속적으로 작업된 코드의 최신버전이 공유되고 있으니 PR을 넣어주시면 검토하여 컨텐츠에 반영해보겠습니다.

alpha v_0.2 (26.02.04)

나.. 너무 많은 업데이트가 있었어...

1. 몬스터를 소환하고 던전에 배치할 수 있음

- 현재 약 100종의 몬스터가 존재함

2. 용사의 던전 침공 구현

- 신규 용사 생성 및 기존 용사의 침공이 가능하도록 처리

- 현재는 용사가 혼자 침공하지만 차후 업데이트를 통해 용사파티가 침공하도록 구현할 예정입니다.

3. 마왕(유저)의 레벨업 구현

4. 마계사전 정보 구체화

5. 조교대상의 조건에 맞는 TRAIT획득 구현

6. 각종 버그 수정

향후 개발 계획

- 다양한 함정 구현

- 잘 훈련(또는 조교)된 용사를 처분하고 spirit획득할 수 있는 포로 처분 기능 구현

- 몬스터의 배치에 따른 시너지 효과 구현

- 몬스터들을 이용해 인간계를 침공하는 침공 기능 구현

- 몬스터 및 캐릭터에게 "스킬!"을 부여(이중타격, 중독, 피해반사 등)

- 조교시 버튼 클릭이 아니라 유저가 직접 명령을 입력하도록 기능개선

코드가 점점 스파게티가 되어가고 있습니다.

많이 생각하고 초반 설계를 시작했습니다만 다시 개발한다면 이렇게 구현하지 않았을텐데... 하는 부분이 한두가지가 아니네요.
